# Panduan aset visual Makmal Cilik

Apabila milestone semasa memerlukan aset baharu, utamakan penjanaan imej terus dalam workflow Codex jika tersedia. Simpan aset ke repository, integrasikan ke UI dan uji pemuatannya. Jangan minta pengguna menjana atau memindahkan aset secara manual kecuali benar-benar perlu. Pengguna mengutamakan workflow ini walaupun menggunakan lebih banyak usage.

- Rujukan rasmi: `assets/reference/makmal-cilik-visual-target.png`. Gunakan sebagai North Star sahaja, bukan production artwork atau imej UI.
- Kekalkan makmal kanak-kanak moden, biru/kuning/hijau/putih, bentuk rounded, gaya mesra pendidikan dan kejelasan pada skrin kecil.
- Jangan muat turun aset rawak dari internet atau menukar gaya tanpa arahan.
- Utamakan WebP untuk ilustrasi/game assets, PNG jika transparensi PNG diperlukan, SVG untuk ikon ringkas. Optimakan saiz untuk web/mobile tanpa menjejaskan kualiti ketara.
- Gunakan folder `assets/branding`, `mascot`, `modules`, `experiments`, `ui`, `deco`, `reference`, `audio`; tambah folder hanya bila diperlukan.
- PICO kekal placeholder sehingga milestone yang sesuai. Apabila diperlukan, jana reka bentuk konsisten dengan rujukan, contohnya `assets/mascot/pico.webp`. Variasi `pico-happy.webp`, `pico-thinking.webp`, `pico-hint.webp`, `pico-success.webp`, `pico-surprised.webp` hanya jika benar-benar digunakan.
- Ikon custom hanya jika memberi nilai berbanding CSS/SVG ringkas. Nama konsisten: `icon-home.svg`, `icon-back.svg`, `icon-sound-on.svg`, `icon-sound-off.svg`, `icon-fullscreen.svg`, `icon-hint.svg`.
- Aset eksperimen dijana apabila eksperimen dibina, contohnya `assets/experiments/electricity/`. Jangan jana semua kemungkinan aset lebih awal.
- Jangan naikkan versi kerana aset ditambah atau mulakan milestone baharu secara automatik.
- Jika penjanaan tidak tersedia, nyatakan batasan dan teruskan dengan placeholder sesuai tanpa mengubah skop.
