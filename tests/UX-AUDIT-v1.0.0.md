# v1.0.0 UX release review

The v0.8.0 audit is retained in UX-AUDIT-v0.8.0.md. This release extends that presentation system to Haiwan, Manusia and Kemahiran Saintifik rather than redesigning it.

- Title/menu/year selection retain blue framing, rounded controls and PICO. Primary actions remain accessible by vertical scroll on portrait screens.
- Seven unit hubs use real per-unit and overall counts. Unit order and exact names remain unchanged. The finale is derived from 35 completed records.
- New activities use inspect → act → observe: care resources visibly change state; pairing shows grouped items; movements show a model; measurement requires alignment; predictions are compared with results.
- Hints retain attention, highlighted control and direct clue stages. Wrong predictions receive no penalty. Reflection follows an activity.
- All new missions use shared short PICO dialogue, five phase markers, completion layout and replay wording. The 15 sets avoid repeated “Hebat!” prompts.
- Unit finales list the five mission names and actual completion. Year 2 finale supplies all three requested exits and real totals.
- Body movement requires only the screen model, not physical movement. Sensory examples require no real tasting or handling.
- Measured ball illustration was corrected to match the instruction; endpoint guide lines clarify ruler reading. Care feedback spelling was corrected.
- Target sizes: 1366×768, 1920×1080, 390×844, 360×640, 800×450. All 35 missions passed the responsive browser matrices. All 15 new missions passed actual keyboard completion.
- Optional motion has a reduced-motion fallback; no colour-only completion or drag-only action. Physical-device and screen-reader validation remain unperformed.

See QA-v1.0.0.md for counted test results, storage coverage, assets and limitations.
